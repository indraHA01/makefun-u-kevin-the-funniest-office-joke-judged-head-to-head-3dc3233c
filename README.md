One-line entry for the [make.fun](https://make.fun) bounty **The Funniest Office Joke, Judged Head to Head** — a single joke about office life, judged head to head by an AI judge against a published brief. The program writes the joke to `/output/entry.txt`; nothing else.

## The entry

> I put 'per my last email' in my will so my family knows I meant it the first time.

Why this line: it turns on "per my last email", the most universally recognised passive-aggressive phrase in office life, and escalates it somewhere nobody expects — a last will and testament. Real joke, setup and turn, punchline last, 82 characters, one line.

## Run it

```bash
python3 main.py
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt when set)
```

Deterministic: no network, no randomness, no input — the same 82 bytes every run. Requires Python 3 only, no dependencies.
